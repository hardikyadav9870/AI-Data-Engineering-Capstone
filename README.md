AI-Ready Data Engineering and Visualization Workflow
Project Title

Customer Churn Analytics and Prediction Platform

Project Overview

This project demonstrates a complete AI-ready data engineering workflow for customer churn analysis and prediction using Python and Machine Learning.

Objectives
Collect and prepare customer data.
Clean and validate datasets.
Perform Exploratory Data Analysis (EDA).
Create meaningful visualizations.
Perform feature engineering.
Build reusable preprocessing pipelines.
Train a Machine Learning model.
Track experiments using MLflow.
Technologies Used
Python
Google Colab
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
MLflow
Joblib
Project Workflow
1. Data Acquisition

Generated a synthetic customer dataset containing customer demographics, tenure, monthly charges and service information.

2. Data Cleaning

Handled duplicate records and checked missing values and invalid values.

3. Data Validation

Performed data quality checks to ensure consistency and correctness.

4. Exploratory Data Analysis

Analyzed customer behavior and churn distribution using statistical summaries and charts.

5. Data Visualization

Created charts using Matplotlib and Seaborn.

6. Feature Engineering

Created additional features such as:

Average Monthly Value
Customer Segment
High Support Customer
7. Data Preprocessing

Built reusable preprocessing pipelines using Scikit-learn, including missing-value imputation, scaling and categorical encoding.

8. Machine Learning

Trained a Random Forest Classifier to predict customer churn.

9. Experiment Tracking

Used MLflow with SQLite to record experiment parameters and evaluation metrics.

Model Evaluation

Evaluated the model using:

Accuracy
ROC-AUC
Confusion Matrix
Classification Report

Dataset Information

The project uses a synthetically generated dataset for educational and demonstration purposes. It does not contain real customer information.

Conclusion

This project demonstrates an end-to-end AI-ready data engineering and visualization workflow that transforms raw data into cleaned, validated and ML-ready datasets.
